About Penny

PennyUtils (or just Penny) is a feature-rich Discord bot designed to bring interactive music streaming, dynamic meme generation, local AI chatting, and moderation utilities to your server.

Privacy Policy

Last Updated: October 13, 2026

1. What Data We Collect

PennyUtils collects the minimum amount of data necessary to function. We store:

  • Discord identifiers and settings: User IDs and server IDs are stored as needed for warnings, favorites, playlists, blacklists, moderation settings, prefixes, and other server configuration.
  • Command usage totals: The bot increments a local count for each recognized command, grouped by the command's canonical name (aliases count under the same name). Arguments and per-user command histories are not included in this counter. Counts are stored in command_usage.json.
  • Moderation and message logs: If a server owner configures a log channel, moderation actions and message edits/deletions are sent there as Discord embeds. Logs may include message text, author and moderator identifiers, channel/message identifiers, attachment filenames, and action details. Purge logs include the contents available to the bot when messages are deleted. If Discord does not provide the message in the bot's cache, the log indicates that its contents are unavailable. Deletion logs identify the moderator only when a matching Discord audit-log entry can be found.
  • AI chat history: The active conversation is kept in bot memory, associated with your Discord user ID, until you clear it, change persona, or the bot restarts. The bot sends the most recent 10 conversation entries as context for each request; older entries may remain in memory until the conversation is cleared.
  • Uploaded audio: When you use the play-file command, the bot streams the attached audio from its Discord attachment URL for playback. It does not intentionally save the audio file to its local data files. The message and attachment remain subject to Discord's own handling and retention.

2. How We Use Your Data

Data is used to provide and maintain the bot's features, such as retrieving saved playlists, applying moderation actions, keeping command totals, and recording events in a server-configured log channel. AI prompts are sent by the bot to the LM Studio server configured by its operator. The bot code uses a local endpoint by default and does not itself send prompts to a hosted AI provider; Discord still processes the messages and attachments you send through Discord.

3. Data Storage and Security

Bot settings, warnings, favorites, playlists, and command totals are stored in local JSON files (bot_data.json, favorites.json, playlists.json, and command_usage.json) on the bot host. Active AI chat history and music queues are held in memory while the bot is running. Configured moderation and message logs are sent to Discord channels selected by the server owner and are subject to Discord's storage, access, and retention controls. The bot operator does not sell personal data.

4. Data Deletion

AI chat history can be cleared with the bot's clear-chat command and is also cleared when you change personas or when the bot restarts. For deletion of persistent bot data associated with you, contact the bot developer. Server owners and administrators manage messages in their configured Discord log channels under their server's policies; deleting a source message does not automatically remove a copy already recorded in a log channel. Command usage totals are aggregate counts and are not attributed to individual users.

5. AI-Generated Content

The superuncensored persona may produce strong language, offensive material, or otherwise inappropriate content. It is not suitable for all audiences. Use discretion; AI responses may be inaccurate or unsuitable and should not be treated as professional advice.
